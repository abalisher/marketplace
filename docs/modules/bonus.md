# Модуль `bonus` — бонусный счёт покупателя

**Статус:** не начат · **Код:** `backend/src/modules/bonus/`

## Назначение
Начисление бонусов за завершённые заказы и их использование как частичной оплаты будущих заказов.

## Модели (план)
- `BonusAccount` — баланс покупателя (физ и юр).
- `BonusTransaction` — начисление/списание/сгорание: дата, заказ-основание, сумма.
- `BonusConfig` — настраиваемый % начисления (уровень платформы/сегмента), макс. % оплаты бонусами, срок сгорания.

## Бизнес-правила (из ТЗ 4.16)
- Начисление: по умолчанию 1% от суммы заказа, ПОСЛЕ закрытия заказа И истечения окна возврата (14 дней).
- Списание: не более настраиваемого % от суммы нового заказа.
- Вывод бонусов на карту/счёт — ЗАПРЕЩЁН, только покупки внутри платформы.
- Сгорание — опционально (настраиваемый срок) + уведомление о скором сгорании (job + subscriber).
- В документах заказа суммы «живыми деньгами» и «бонусами» показываются раздельно (интеграция с `documents`).

## API (план)
- `/store/bonus` — баланс, история, применение к заказу.
- `/admin/bonus` — конфигурация процентов и порогов.
