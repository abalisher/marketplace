# Модуль `documents` — автогенерация документов

**Статус:** не начат · **Код:** `backend/src/modules/documents/`

## Назначение
Автоматическое формирование PDF-документов по событиям заказа и их хранение с версионностью.

## Модели (план)
- `Document` — тип (счёт/накладная/внутренний АВР), заказ-основание, версия, файл, кому виден.
- `DocumentTemplate` — шаблоны с реквизитами продавца.

## Бизнес-правила (из ТЗ 4.10)
- Счёт на оплату — автоматически сразу после оформления заказа, отправляется покупателю (ЛК + email/push).
- Накладная — при отгрузке; при частичной отгрузке — на отгруженную часть.
- Внутренний АВР для юрлиц — информационный документ платформы (НЕ официальный).
- Официальные АВР/ЭСФ — бухгалтер вручную на kgd.gov.kz; платформа даёт экспорт исходных данных заказа (API/выгрузка) — вне периметра автоматизации MVP.
- Суммы «деньгами» и «бонусами» — раздельно (данные из `bonus`).
- Хранение: у обеих сторон, с версионностью и историей.

## Интеграции
- Вызывается из workflows (`placeOrder`, `partialFulfillment`), не напрямую из API-роутов.
- Экспорт для 1С — через `/admin`-эндпоинты и/или webhooks.
