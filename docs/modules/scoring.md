# Модуль `scoring` — рейтинг и лимиты отсрочки

**Статус:** не начат · **Код:** `backend/src/modules/scoring/`

## Назначение
Расчётный рейтинг покупателя, определяющий доступный лимит отсрочки платежа/кредита для юрлица.

## Модели (план)
- `ScoreCard` — текущий рейтинг покупателя + компоненты расчёта, история пересчётов.
- `ScoringRule` — настраиваемые правила: вес критерия, пороги → НЕ хардкод, редактируются админом/руководителем продавца.
- `CreditLimit` — одобренный лимит отсрочки компании, использованная часть.

## Критерии рейтинга (из ТЗ)
История платежей (просрочки/своевременность) · количество и сумма заказов · возвраты/отмены · срок работы с платформой.

## Бизнес-правила
- Пересчёт — событийно (закрытие заказа, просрочка) и/или кроном (`src/jobs/`).
- Продавец видит карточку рейтинга ПЕРЕД одобрением отсрочки.
- Заказ с постоплатой блокируется, если превышает свободный лимит.
- Изменения лимитов логируются (аудит из ТЗ 5.3).

## API (план)
- `/admin/scoring` — правила, карточки рейтинга, ручная корректировка лимита.
- Внутреннее: workflow `placeOrder` спрашивает свободный лимит при постоплате.
