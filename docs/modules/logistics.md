# Модуль `logistics` — доставка, рейсы, GPS

**Статус:** не начат · **Код:** `backend/src/modules/logistics/`

## Назначение
Доставка транспортом продавца: рейсы водителей, тарифная сетка, GPS-трекинг в реальном времени,
подтверждение отгрузки фото/подписью, забор возвратов с чек-листом.

## Модели (план)
- `Trip` — рейс: водитель, склад загрузки, статус.
- `TripStop` — точка рейса (заказ/возврат): адрес, статус, фото, подпись, чек-лист осмотра (для возврата).
- `DeliveryTariff` — тарифная сетка: вес/объём/зона → стоимость (настраивается продавцом).
- `GpsPing` — координаты водителя (поток; хранить сжато, отдавать через realtime-канал).

## Бизнес-правила (из ТЗ 4.8–4.9)
- Стоимость доставки считается по тарифной сетке от веса/объёма (из карточек товара!) и зоны.
- GPS водителя виден покупателю и диспетчеру на карте в реальном времени.
- Возврат: курьер при заборе делает осмотр по чек-листу с фото прямо в приложении.
- Доставка возврата оплачивается покупателем по той же тарифной сетке.
- Фаза 2: партнёрский транспорт через платформу — тариф/перевозчик за интерфейсом, не хардкодить «свой транспорт».

## API (план)
- `/store/delivery` — расчёт стоимости, трекинг заказа (позиция водителя).
- `/driver/*` — рейсы водителя, статусы, загрузка фото/подписи, GPS-пинги (используется apps/driver).
- `/admin/logistics` — тарифы, назначение рейсов, карта диспетчера.
